# Support

This repository is maintained as a CI/CD learning lab focused on Jenkins
pipelines. Questions and suggestions are welcome when they improve pipeline
clarity, safety, repeatability, or documentation.

## Best Ways To Ask For Help

- Open an issue for unclear pipeline stages, missing setup notes, or unsafe CI
  examples.
- Include the affected Jenkinsfile, command, or documentation section.
- Share the smallest failing pipeline behavior you can describe.

## Good Issue Examples

- A pipeline stage does not explain its purpose.
- A credentials example needs safer guidance.
- A rollback or deployment note is missing an important assumption.
- A CI example should document artifacts, reports, or quality gates.

## Out Of Scope

- Production Jenkins administration support.
- Private credentials, internal URLs, or company-specific infrastructure.
- Large platform migrations unrelated to the learning goals.
