# Technical Scope

This file defines what the project is meant to prove and what it does not claim yet.

## In Scope

- Jenkins pipeline design.
- CI/CD quality gates.
- Credentials, artifacts, rollback, and release strategy.
- Delivery architecture documentation.

## Out of Scope for Now

- Full production deployment platform.
- Company-specific Jenkins administration.
- Long-lived infrastructure ownership.
- Automatic production deployment without approval context.

## Scope Statement

The project is scoped to prove delivery engineering judgment. The next milestone
is adding a runnable Java pipeline that produces visible artifacts and failure
feedback.
