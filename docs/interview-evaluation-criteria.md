# Interview Evaluation Criteria

Use these criteria to evaluate the project during a technical interview.

## Baseline Signal

- Explains common Jenkins pipeline stages.
- Understands build, test, package, and artifact flow.
- Navigates the delivery documentation.

## Strong Signal

- Connects pipeline stages to developer feedback.
- Discusses credentials, quality gates, approvals, and artifacts.
- Explains how failures should stop the release flow.

## Senior Signal

- Treats CI/CD as a reliability and recovery system.
- Balances speed, safety, traceability, and rollback.
- Designs pipelines around team behavior, not only automation syntax.
