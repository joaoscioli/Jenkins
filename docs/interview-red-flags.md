# Interview Red Flags

Use this file to avoid weak signals during a technical interview.

## Avoid Saying

- "The pipeline just runs commands."
- "Deployment should always be automatic."
- "Secrets can be passed as variables if the repo is private."
- "Rollback is an operations problem."

## Say Instead

- A pipeline is part of delivery architecture and production reliability.
- Deployment automation should match risk, ownership, and approval needs.
- Secrets need managed credentials, masking, and rotation thinking.
- Rollback strategy belongs in the release design.
