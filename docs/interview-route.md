# Interview Route

Use this route to navigate the repository during a technical interview.

## Start Here

Open the README and explain that this is a Jenkins CI/CD lab for Java and Spring
Boot delivery workflows.

## Show The Core Examples

Compare the Maven, Docker image, and Spring Boot quality-gate Jenkinsfiles.
Explain what each pipeline proves and what risk each stage reduces.

## Discuss Engineering Judgment

Use the credentials, artifact, release, rollback, and troubleshooting docs to
show that pipeline design is part of production readiness.

## Close With The Next Step

Explain that a before-and-after pipeline review would make the repository even
stronger for discussing CI/CD design decisions.
