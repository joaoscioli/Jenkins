# Key Talking Points

Use these points to keep the interview conversation focused.

## Lead With

- CI/CD is part of engineering ownership, not a separate afterthought.
- Pipelines should provide fast feedback and useful artifacts.
- Credentials, timeouts, release gates, and rollback plans reduce delivery risk.

## Go Deeper On

- Why each Jenkinsfile has a different delivery purpose.
- How artifacts help debugging and release review.
- Where secrets should live and why they should not appear in logs.

## Avoid Overclaiming

- Do not say every pipeline should auto-deploy to production.
- Explain where manual approval and environment controls make sense.
