# Pre-Interview Checklist

Use this checklist before presenting the repository.

## Review Before The Call

- Open the fast review path and interview case study.
- Compare the Maven, Docker, and quality-gate Jenkinsfiles.
- Prepare one pipeline failure and how you would debug it.
- Know where credentials, artifacts, and rollback concerns appear.

## Be Ready To Show

- Java Maven Jenkinsfile
- Docker image Jenkinsfile
- Spring Boot quality gates Jenkinsfile
- pipeline review playbook

## Strong Close

Explain that CI/CD reduces delivery risk and makes failures easier to act on.
