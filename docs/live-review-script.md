# Live Review Script

Use this script when sharing the repository during an interview.

## Opening

This repository shows CI/CD thinking around repeatable delivery, quality gates, and operational recovery.

## Walkthrough order

1. Start with `README.md` to frame pipeline goals.
2. Open a Jenkinsfile and explain each stage.
3. Show repository validation and quality gates.
4. Discuss credential handling and artifact strategy.
5. Close with rollback and troubleshooting.

## Strong signal

The pipeline is presented as engineering risk control, not only automation syntax.
