# Next Demo Slice

stronger in a technical interview.

## Goal

Add a runnable Jenkins pipeline for a Java Maven project.

## Scope

- Checkout, build, test, package, and archive artifacts.
- Publish test results.
- Fail fast on compilation or test errors.
- Document the expected pipeline feedback for developers.

only pipeline terminology.
