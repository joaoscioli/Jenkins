# Hiring Manager Summary

This repository supports the portfolio by showing CI/CD and delivery awareness.

## Why It Matters

It demonstrates that backend work includes build feedback, artifacts, release
control, credentials, rollback, and troubleshooting.

## What To Notice

- Jenkinsfiles for Java Maven, Docker image, and Spring Boot quality gates.
- Documentation for credentials, artifacts, releases, and rollback.
- Pipeline review and troubleshooting guides.
- Clear connection between CI/CD and production readiness.

## Interview Signal

This project is useful for discussing delivery pipelines, secure automation,
release discipline, and operational thinking.
