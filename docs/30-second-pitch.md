# 30-Second Pitch

This repository is a Jenkins CI/CD lab for Java and Spring Boot delivery.

It demonstrates that I think beyond application code: build feedback, tests,
artifacts, Docker packaging, credentials, quality gates, release strategy,
rollback, and troubleshooting are part of engineering ownership.

In an interview, I would use this repository to discuss pipeline design,
delivery risk, secure automation, and how CI/CD supports production readiness.
