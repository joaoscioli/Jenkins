# Reviewer FAQ

## What should I review first?

Start with the README, pipeline review playbook, release strategy, and rollback
strategy.

## What is the main technical signal?

The project treats CI/CD as delivery architecture, with attention to quality
gates, credentials, artifacts, traceability, and rollback.

## What is intentionally unfinished?

A runnable sample application pipeline and deeper scan examples can still be
added for stronger hands-on validation.

## What should we discuss in an interview?

Discuss pipeline stages, safe deployments, credential handling, production
approvals, and operational ownership.
