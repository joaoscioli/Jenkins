# Contributing

This repository is maintained as a CI/CD learning lab.

## Working Style

- Add one pipeline concept at a time.
- Keep Jenkinsfiles readable and explain each important stage.
- Document operational trade-offs, not only commands.
- Prefer examples that connect CI/CD to Java and Spring Boot delivery.

## Before Opening A Pull Request

- Run the repository checks when possible.
- Update the related documentation page.
- Confirm that pipeline snippets remain easy to review.

## Review Focus

Reviewers should look for safe delivery practices, clear pipeline stages,
artifact handling, credentials discipline, and rollback awareness.
